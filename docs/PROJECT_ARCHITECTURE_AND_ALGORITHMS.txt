  +-------------------------------------------------------------+
  | Canonical Event Payload Assembly (src/lib/contract/d1.ts)   |
  | {                                                           |
  |   streamId: "stream_disposafe_cannula",                     |
  |   eventType: "InspectionRecordEvent",                       |
  |   timestamp: "2026-08-24T00:00:00Z",                        |
  |   payload: { batchId, checkedQty, rejectedQty, defects },   |
  |   metadata: { sourceFile: "Aug2026.xlsx", cell: "Sheet1!C4"}|
  | }                                                           |
  +------------------------------+------------------------------+
                                 |
                                 v
  +-------------------------------------------------------------+
  | Cryptographic Content Hasher (src/lib/contract/hash.ts)     |
  | Hash = SHA256( JSON.stringify( CanonicalSort(EventObject) ))|
  +------------------------------+------------------------------+
                                 |
                                 v
  +-------------------------------------------------------------+
  | Append-Only Event Store (Supabase PostgreSQL / Memory)      |
  | - If Hash exists: DEDUPLICATE (No-op, prevents double-count)|
  | - If Hash is new: INSERT INTO event_ledger                  |
  | - If record corrected: INSERT CorrectionEvent (supersedes)  |

6. DETERMINISTIC MASS-BALANCE & DISCREPANCY RECONCILIATION
================================================================================

              [ Day-Record Extracted from Excel ]
                               |
                               v
+---------------------------------------------------------------+
| STEP 1: Recompute Total Defects from Raw Atomic Cells         |
|         Total_Defects_Recomputed = Sum(D_1 + D_2 + ... + D_m) |
+------------------------------+--------------------------------+
                               |
                               v
+---------------------------------------------------------------+
| STEP 2: Calculate Defect Balance Delta                        |
|         Delta_Defect = Rejected_Qty - Total_Defects_Recomputed|
+------------------------------+--------------------------------+
                               |
                               v
+---------------------------------------------------------------+
| STEP 3: Calculate Yield Mass Balance Delta                    |
|         Delta_Yield = Checked_Qty - (Accepted_Qty + Rej_Qty)  |
+------------------------------+--------------------------------+
                               |
                 +-------------+-------------+
                 |                           |
                 v (Delta_Defect == 0 AND    v (Delta != 0)
                    Delta_Yield  == 0)       |
  +--------------------------------+  +-------------------------------+
  | STATUS: BALANCED & VERIFIED    |  | STATUS: DISCREPANCY DETECTED  |
  | - Direct commit ready          |  | - Flagged in Review UI        |
  | - Rejection Rate = Rej / Chk   |  | - Displays exact source cell  |
  | - Yield Rate = Acc / Chk       |  |   coordinates (e.g. Sheet1!F8)|
  +--------------------------------+  | - Operator resolves in UI     |
                                      +-------------------------------+
